# BimaAlert - Motor Policy Expiry Reminder & Customer Manager
(बीमा रक्षक - मोटर पॉलिसी रिमाइंडर)

## How to Deploy to Vercel (100% Free Lifetime)
1. Upload this folder to GitHub (create a new repository on https://github.com/new).
2. Go to https://vercel.com and select "Continue with GitHub".
3. Click "Import" next to your repo and click "Deploy".
4. You get a permanent live link like https://bima-alert.vercel.app!

## How to Run Locally on Computer
```bash
npm install
npm run dev
```
